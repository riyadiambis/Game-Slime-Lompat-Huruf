# Game Slime Lompat Huruf

Game web edukasi lompat-lompat voxel 3D yang dirancang untuk membantu anak-anak yang sedang belajar membaca dengan menyusun kata 4 huruf secara menyenangkan.

## Cara Main
- **Keyboard (PC/Laptop):**
  - Gunakan tombol **WASD** atau **Tombol Panah** untuk menggerakkan slime dan melompat ke blok huruf.
  - Susun huruf demi huruf hingga membentuk kata 4 huruf yang tepat.
- **Layar Sentuh (Smartphone/Tablet):**
  - Gunakan kontrol tombol arah / tombol sentuh yang tersedia di layar untuk melompat ke huruf target.
